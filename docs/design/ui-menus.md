## 視覺方向（D29）

| 項目 | 內容 |
|---|---|
| 主題 | 直式像素風打磚塊（Android）。玩家用擋板接到金球或黑球後，要從 3 個道具中選 1 個，選到的立刻生效；金球是好事、黑球是壞事，玩家要看懂「這是什麼、會怎樣」 |
| 色彩 | 面板底 `K`（與 UI 區同色）；金球框用黃色階 `A B Y C D`；黑球框用 D21 暗紫 `_ < > ,`；文字白 `W`；全部取自 D01 |
| 字型 | Cubic 11 一種字型，全部 22 px（2 倍），以大小一致取代層級；層級靠位置（名稱在上、說明在下）與顏色（名稱、說明同為 `W`，標題用金／紫） |
| 版面 | 畫面中央一塊 304×432 面板；上方標題，下方 3 個直排選項（每個 280×112） |
| 原則 | 1. 圖示、名稱、效果三者一起出現，玩家不看字也能靠圖示判斷 2. 金球與黑球「外框顏色＋標題字」兩個線索都不同，不只靠顏色 3. 選項要大、間隔要夠，避免誤觸 |

自我檢查（已換掉的通用預設）：
- 不用漸層、發光、統一圓角卡片；面板與選項都是直角斜面，和磚塊、擋板同一語彙
- 不用「大數字＋小標籤」；開頭放的是該球本身的圖示（**修訂，待使用者確認（2026-10-28）**：D32 的 40×40 金球、黑球，原為 D20、D21 的 16×16）
- 動態只有一個重點：入場時 3 個選項依序滑入（像抽出 3 張牌）；其餘是回應操作的回饋

   **四、觸控區與誤觸防護**

   | 項目 | 規格 | 理由 |
   |---|---|---|
   | 觸控區 | 整個選項矩形 **280×112**（比下限 44×44 大很多） | 下限依據：本遊戲內部寬 360 與常見 360 dp 寬手機相當，1 內部像素約等於 1 dp；Material 建議 48 dp、Apple 建議 44 pt，使用者規定至少 44×44。選擇不可反悔，所以給 112 高（也是為了容納最多 3 行 22 px 的說明） |
   | 選項間隔 | 8 px，不屬於任何選項（按到間隔無作用） | 兩個選項之間留死區，減少按到隔壁 |
   | 選取時機 | **手指放開（touch up）時**，且按下與放開都在同一個選項內才算選中 | 手指滑動中不會誤選；按下後發現按錯可以滑開取消 |
   | 入場鎖定 | 畫面開始出現的 0~500 ms 不接受觸控 | 球型道具是在玩家拖擋板時接到的，手指還在動；先讓玩家看到畫面再選 |
   | 多點觸控 | 只處理第一個按下的手指，其他忽略 | 避免兩指同時選兩個 |
   | 選定後 | 立刻忽略所有輸入，直到畫面關閉 | 避免連點選到第二個 |
   | Android 返回鍵／手勢 | 不關閉本畫面 | 規則是「必須 3 選 1」 |
   | UI 區暫停鈕（x 304~359、y 0~31） | 本畫面開啟期間不回應 | 避免疊畫面 |
   | 二次確認 | 無，點了就生效 | 使用者已決定（2026-10-27） |
   | 無障礙 | 見七 | |
