### 4.2 出圖流程(pixel-loom)

1. PM 擬指令 → 給使用者看 → 派 designer 用 pixel-loom 畫。新的一批先畫 2~3 張試稿確認畫風,再畫其餘。
2. designer 輸出 draft 預覽(`docs/design/preview/dNN/`,含 `_x4` 與總覽)→ PM 用 Read 看過後用 SendUserFile 給使用者。圖片免 QA。
3. 使用者確認後,designer 跑 `pixel_review` → `pixel_review_submit` → 正式匯出到 `game/art/<資料夾>/`(非 draft、絕對路徑)。
4. PM 清點張數與尺寸;能比對時逐像素比對正式檔與預覽。
5. 交 engineer 實作 → QA → JEV。
