# 特殊磚與魔王規格（圓形磚、寶箱、金幣磚、魔王、血條、BOSS 警告）

- 狀態：**已確認、已匯出**（2026-10-29）。D39~D44 規則全部決定（使用者確認 Q1~Q13，見文末「已決定」表）；58 張圖經使用者確認（含我調整的 5 項：內凹轉角 3×3、圓形 f3 碎片 4×4、圓形 f2 十字縫、金幣側面 4 px、裂痕改 `K`＋`Q`；BOSS 字維持原樣、不畫中文標註），已正式匯出 58 張 PNG 到 `game/art/special40/`（非 draft；每項的「正式匯出紀錄」見各項末）
- 依據：`pixel-art-bricks.md` D01（調色盤）、D02（畫風）、`brick-size.md` D31（40×20 母版）、D38（格式範本）、`ui-menus.md` D37（炸彈標記）
- 使用者已決定（本稿遵守）：
  - 圓形磚 20×20，置中於 40×20 格（兩側各空 10），碰撞為直徑 20 的圓；寶箱、金幣、圓形固定 1 層；寶箱橙、金幣黃、圓形紫，不屬七色
  - 金幣磚破壞後掉落金幣（10、50、100 三種），用擋板接，三種外觀要分得出來
  - 魔王不畫臉；配色用**方案 B「黑曜青紋」**（2026-10-29 確認）；由 40×20 格拼成；支援 160×20、正方形、不規則形、一關兩隻各自血量；用模組拼接
  - 魔王畫面上方一條血條（含層數數字）；進入魔王關卡跳出「BOSS」警告
  - 魔王逐格破壞：血量降到一定程度就掉一格，歸零時最後一格破壞；**掉哪一格＝從剩下的格子中隨機挑一格**（實際遊戲掉格位置為隨機；總覽圖的掉格畫面只是示意拼接）
  - 圓形磚、寶箱畫風試稿通過（2026-10-29）
- 座標：螢幕內部解析度 360×800；關卡區 x 20~339、磚從 y 68 起、一排 8 格；UI 區 y 0~31、上邊框 y 32~51、y 52~67 為磚上方空白帶；擋板上緣 y 763
- 欄、列、座標一律從 0 起算；「格內座標」＝相對該 40×20 格左上角

## 視覺方向

| 項目 | 內容 |
|---|---|
| 主題 | 直式打磚塊 Roguelike（Android）；玩家要一眼分清「普通磚、特殊磚、魔王」，魔王要有壓迫感但不可愛、不畫臉 |
| 色彩 | 只用 D01：圓形磚紫色階 `m n V p q`；寶箱橙色階 `a O d b c`＋鋼灰 `i e f g j`；金幣黃色階 `A B Y C D`；魔王用 `Q Z z v`＋青 `w x *` 能量紋；描邊一律 `K`。**沒有新增任何顏色** |
| 字型 | 無字型；數字沿用 D31 的 7×9 白字加 `K` 描邊；「BOSS」為自繪像素字（非外部素材，無授權問題） |
| 版面 | 見各項；魔王血條放在 y 52~67 空白帶，BOSS 警告橫條置於關卡區中央 |
| 原則 | 1. 魔王靠「深色＋青色能量紋＋大面積」分辨，不靠臉 2. 磚外框由相鄰格決定，任何形狀用同一組元件拼出 3. 能用規則產生或沿用的圖就不新畫（閃白、破壞 F4、無敵外框、炸彈標記） |

自我檢查（已換掉的通用預設）：不用漸層、不用抖色；魔王不是「紫色大磚＋臉」；血條用「掉格刻度」承載資訊，不是裝飾。
