## 4. 像素美術：畫風與做法(畫新圖時必讀)

### 4.1 畫風(詳細規則見設計稿 D01、D02)

| 項目 | 規則 |
|---|---|
| 細緻度 | **泰拉瑞亞式**細緻像素風(只參考風格，不可複製任何圖) |
| 光源 | 左上：上緣、左緣亮；下緣、右緣暗 |
| 描邊 | 1 px `K`(#1B1A2E 深藍黑) |
| 立體 | 2 px 斜面；每種材質 **5 階色階**(T1 最亮 ~ T5 最暗) |
| 高光 | 左上可加 `W` 白色高光條 |
| 紋理 | 有材質感的紋理(凹坑、裂痕、木紋、鉚釘、刮痕、斜紋),**不用隨機點、不用抖色、不用漸層** |
| 調色盤 | 全檔共用 D01(目前 60 色)。字母已全部用完，新色用數字或符號當代號。新色要加進 D01 並標註「Dxx 用」 |
| 顏色是玩法資訊 | 可破壞磚塊主色限定**彩虹七色**(紅橙黃綠藍靛紫),彩虹磚依顏色破壞同色磚；非磚塊物件要和七色分得出來 |
| 第二線索 | 顏色之外一定有形狀記號，也照顧色盲 |
| 狀態 | 一般物件有正常、被擊中(1 幀)、破壞 4 幀(小磚每幀 60 ms、魔王 100 ms)。被擊中預設「除 `K`、`.` 外全部變 `W`」,金屬類可改用火花(D14) |

### 4.4 D16 HUD 球狀態(已確認)

| 項目 | 內容 |
|---|---|
| 格位 | 7 格固定順序：強化、fever、減速、加速、穿透、火焰、炸彈；沒有的留空不補位。減速與加速不會同時出現，所以最多 6 格 |
| 圖示 | 共用 16×16 正方形底板，內容在 12×12 框內 |

| 5 秒狀態 | 穿透、火焰、炸彈：白色填色依剩餘時間從右往左縮短；最後 1 秒閃爍 |
| 時間疊加 | 再撿到相同狀態：剩餘時間 + 新時間；以疊加後的剩餘時間為新總時間，條回到全滿再縮短 |
| 附魔、fever | 線段全滿白色、不縮短 |
| 階段狀態 | 線段切成和階段數一樣多的小段；第 1 段白、往右漸深；第 n 階填滿前 n 段。強化 7 段、減速 3 段、加速 4 段 |
| 球速 | 加速與減速互相抵銷，只顯示淨值。例：加速 3 格再撿到減速 → 顯示加速 2 格 |
| 尺寸 | 每格 22×22,格距 4,整排 178×22 |

### 4.5 做法與流程

1. PM 擬指令 → **先完整給使用者看** → 派 designer。
2. designer 在設計稿新增項目，用文字網格畫(一字元一像素,`.` 透明),寫清楚規則。
3. PM 先記錄 `docs/design/preview/` 所有 PNG 的 SHA256,執行轉檔工具 `powershell -ExecutionPolicy Bypass -File tools\pixelart\run.ps1`,再跑 `verify.ps1`,然後比對雜湊：只有預期的圖與 `overview.png` 可以變動。
4. 請 designer 用 Read 看 `docs/design/preview/Dxx_*_x8.png` 自檢。原則上 1 輪，有問題才修第 2、3 輪。
5. 把 PNG 用 SendUserFile 給使用者看，使用者確認後定案。
6. 需要新的自動產生規則(換色、拼接…)時，派 engineer 改工具 → QA 獨立驗證 → JEV 判斷驗收。只畫單張圖時不用改工具。
7. 已確認的項目：照 CLAUDE.md 應請設計師刪除，刪除前把內容放進工程師派工指令。**遊戲程式尚未開始，所以目前全部保留在設計稿中**,等派工程師時再處理。

### 4.6 注意事項(踩過的坑)

| 項目 | 說明 |
|---|---|
| **禁用 replace_all** | designer 曾用 replace_all 誤改已定案像素。指令裡一律寫「不可使用 replace_all;改完用 Grep 確認既有網格沒變」 |
| 標題命名 | 工具依網格標題命名。新項目一律用「中文名稱（id: 英文代號）：」,代號小寫英文、數字、底線，同項目內不重複 |
| 欄列編號 | 位置描述一律**從 0 起算** |
| 固定句型 | 需要工具解析的尺寸用固定句型，例如「圖高（本體）：8」「左端寬：8」 |
| 寫死的規則 | D12 的「圓形專用」「魔王裂痕疊加」「多層磚破壞」「扣層」、D13 各狀態用哪些分段，都寫死在工具裡，改設計稿文字不會生效，要改需派 engineer |
| 已定案項目 | 不改已定案的網格；設計稿刪除任何項目前要使用者同意 |
| 用量上限 | subagent 可能因用量上限中斷(本次 designer 中斷過 1 次)。恢復時用 SendMessage 接續，並請它先檢查網格是否寫完、```text 是否成對 |
| 背景色 | x6/x8 預覽圖是透明背景；`W` 白色像素(火花、HUD 白線)在白底檢視器上看不到，要看 `overview.png` 的深色底 |
| 工具清檔 | 轉檔工具每次會清掉輸出資料夾再重寫；設計稿刪掉的網格，對應 PNG 下次轉檔就會消失 |
| 使用者會中途改方向 | 設計師工作中使用者常補充需求；用 SendMessage 排進設計師的佇列即可，不用等他做完 |

## 5.5 下一步：功能型磚塊(使用者 2026-10-24 決定)

**從 README 整理出的需求(派 designer 前先和使用者確認)**

| 磚塊 | README 規則 | 美術上要注意 |
|---|---|---|
| 雷射 | 打出一道雷射讓一整排磚塊層數減 1;有使用次數，被球碰到次數減 2,歸零破壞；雷射被不可破壞磚擋下 | 磚本體、剩餘次數顯示、雷射光束(橫向一整排) |
| 閃電 | 打出和使用次數一樣多的閃電，隨機位置的可破壞磚減 2 層；被碰到次數減 1,歸零破壞；不能打不可破壞磚 | 磚本體、剩餘次數、閃電落下效果 |
| 爆炸 | 被碰到即爆炸，周圍可破壞磚不論層數直接破壞；只能碰 1 次 | 磚本體、爆炸範圍效果(和 D15 炸彈標記、README 炸彈道具爆炸要分得開) |
| 彩虹 | 被碰到時隨機挑畫面上一種可破壞磚的顏色(不含魔王),破壞該色全部磚 | 磚本體本身用彩虹色；**不能被當成七色之一**(它不是同色磚);發動時的效果 |
| 傳送 | 成對出現，碰到的為入口，其餘任一為出口(隨機),出來角度隨機，無次數限制 | 入口/出口是否要區分、成對的視覺關聯、傳送效果 |
| 死神 | 直接破壞碰到的球；有次數限制，歸零破壞 | 磚本體、剩餘次數、破壞球的效果(球的消失沿用 D15 `ball_vanish_f1~f4`) |

**通用待確認**

| 項目 | 說明 |
|---|---|
| 尺寸 | 預設和一般磚相同 32×16(README 沒寫) |
| 顏色 | 功能型磚**不屬於七色同色磚**(彩虹磚只挑可破壞磚的顏色),配色要和七色、鋼灰擋板、不可破壞磚分得開；每種靠形狀記號辨識 |
| 剩餘次數 | 雷射、閃電、死神有次數；要不要顯示、怎麼顯示(數字、刻度、線段如 D16) |
| 狀態 | 被擊中、破壞 4 幀是否沿用 D12 規則；發動效果要不要畫 |
| 無敵 | 減益「無敵」時所有磚(魔王除外)變不可破壞，功能型磚是否也套 D14 疊加外框 |
| 炸彈標記 | README 說炸彈只標記 `可破壞磚塊`;功能型磚會不會被標記要問使用者 |
| 分批 | 6 種一次畫或分批畫，由使用者決定 |
