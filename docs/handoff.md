## 4. 像素美術：畫風與做法(畫新圖時必讀)

### 4.1 畫風(已定案，詳細規則見設計稿 D01、D02)

| 項目 | 規則 |
|---|---|
| 細緻度 | **泰拉瑞亞式**細緻像素風(只參考風格，不可複製任何圖) |
| 光源 | 左上：上緣、左緣亮；下緣、右緣暗 |
| 描邊 | 1 px `K`(#1B1A2E 深藍黑) |
| 立體 | 2 px 斜面；每種材質 **5 階色階**(T1 最亮 ~ T5 最暗:T1 最亮邊與高光、T2 亮面、T3 主色、T4 暗部、T5 最暗與裂痕) |
| 高光 | 左上可加 `W` 白色高光條 |
| 紋理 | 有材質感的紋理(凹坑、裂痕、木紋、鉚釘、刮痕、斜紋),**不用隨機點、不用抖色、不用漸層** |
| 調色盤 | 全檔共用 D01(目前 52 色，不受 32 色限制)。新色要加進 D01 並標註「Dxx 用」 |
| 顏色是玩法資訊 | 可破壞磚塊主色限定**彩虹七色**(紅橙黃綠藍靛紫),彩虹磚依顏色破壞同色磚；非磚塊物件(擋板、不可破壞磚、魔王、球…)要和七色分得出來 |
| 第二線索 | 顏色之外一定有形狀記號(數字、鎖、錢幣、圓形、臉、鉚釘…),也照顧色盲 |
| 狀態 | 一般物件有正常、被擊中(1 幀)、破壞 4 幀(小磚每幀 60 ms、魔王 100 ms)。被擊中預設「除 `K`、`.` 外全部變 `W`」,金屬類可改用火花(D14) |

### 4.2 已完成的美術

| 項目 | 內容 |
|---|---|
| D12 可破壞磚塊 | 母版：一般磚(紅)、寶箱(橙木 + 鋼灰金屬)、金幣(黃 + 「S」錢幣)、圓形(紫)、魔王(暗紫灰臉，不在七色內)、通用破壞 F1~F4、數字 0~9(5×7)。一般磚七色、多層磚 1~14 層(藍 1~9 = 第 1~9 層、綠 0~4 = 第 10~14 層)、被擊中、各色破壞幀由工具自動產生 |
| D13 擋板 | 鋼灰金屬板 + 青色小燈 + 稀疏鉚釘；左端 8 + 中段 16 px 圖塊重複(最後一塊取最左 r 欄)+ 右端 8;狀態：正常、被擊中、槍(兩端 8×12 砲管、黃燈)、吸附(上緣綠色黏液)、槍加吸附(兩端砲管 + 中段黏液);隱形由程式調透明度 |
| D14 不可破壞磚塊 | 深灰藍厚鋼板(`s`、`y` 色)+ 十字鋼條 + 中央黃銅螺栓 + 斜紋防滑板；被擊中為火花(不閃白)。減益「無敵」採**做法 A**:在原磚上疊金屬外框疊加層(`invincible_a_overlay`),原磚顏色與數字可見，5 秒後移除 |

### 4.3 做法與流程

1. PM 擬指令 → **先完整給使用者看** → 派 designer。
2. designer 在設計稿新增項目，用文字網格畫(一字元一像素,`.` 透明),寫清楚規則。
3. PM 執行轉檔工具：`powershell -ExecutionPolicy Bypass -File tools\pixelart\run.ps1`,再跑 `verify.ps1`;並比對既有輸出沒被改到。
4. 請 designer 用 Read 看 `docs/design/preview/Dxx_*_x8.png` 自檢。原則上 1 輪，有問題才修第 2、3 輪。
5. 把 PNG 用 SendUserFile 給使用者看，使用者確認後定案。
6. 需要新的自動產生規則(換色、拼接…)時，派 engineer 改工具 → QA 獨立驗證 → JEV 判斷驗收。只畫單張圖時不用改工具。

### 4.4 注意事項(踩過的坑)

| 項目 | 說明 |
|---|---|
| **禁用 replace_all** | designer 曾用 replace_all 改擋板，誤改已定案 D12 寶箱 1 個像素。指令裡一律寫「不可使用 replace_all;改完用 Grep 確認既有網格沒變」 |
| 標題命名 | 工具依網格標題命名。新項目一律用「中文名稱（id: 英文代號）：」,代號小寫加底線、同項目內不重複。沒有 id 的標題容易撞名而報錯 |
| 欄列編號 | 位置描述一律**從 0 起算** |
| 固定句型 | 需要工具解析的尺寸用固定句型，例如「圖高（本體）：8」「左端寬：8」「中段圖塊寬：16」 |
| 寫死的規則 | D12 的「圓形專用」「魔王裂痕疊加」「多層磚破壞」「扣層」、D13 各狀態用哪些分段，都寫死在工具裡，改設計稿文字不會生效，要改需派 engineer |
| 已定案項目 | 不改已定案的網格；設計稿刪除任何項目前要使用者同意 |
| 用量上限 | subagent 可能因用量上限中斷，已寫的內容會留下但可能不完整。恢復時用 SendMessage 接續，並請它先檢查網格是否寫完、```text 是否成對 |
| 背景色 | x6/x8 預覽圖是透明背景；被擊中(閃白)在白底上只剩黑框，屬正常 |

| 項目 | 內容 |
|---|---|

## 5. 下一步：畫球

**從 README 整理出和球有關的需求(派 designer 前先和使用者確認)**

| 項目 | 內容 |
|---|---|
| 尺寸 | 8×8(暫定)、碰撞為圓形；速度 240 px/s,可加減速(−3~+4 階) |
| 數量 | 分裂、多重分裂會讓球很多；fever 模式門檻是 **50 顆以上**。球要小、清楚，同時很多顆時畫面不能太亂 |
| 對比 | 要在深色背景、彩虹七色磚、鋼灰擋板、深灰藍不可破壞磚上都看得清楚；不能和七色混淆 |
| 增益狀態 | 穿透(5 秒)、火焰(5 秒，周圍 3×3 減層)、炸彈(5 秒，被碰到的磚會被標記，結束後爆炸)、強化(每次減層 +1,最多 7)。付費道具「附魔」可讓穿透或火焰持續整局 |
| 其他相關 | 吸附(球黏在擋板上)、黑洞(碰到擋板消失)、大黑洞(只剩 1 顆)、死神磚(直接破壞球)、fever 模式 |
| 可能需要的圖 | 正常、各狀態外觀(穿透、火焰、炸彈；強化是否要顯示由使用者決定)、球消失或被破壞的效果、fever 模式外觀；炸彈狀態的「磚塊標記」可能也要畫 |
| 待確認 | 哪些狀態要畫、狀態同時存在時怎麼顯示、是否加拖尾、要不要有被擊中幀 |
