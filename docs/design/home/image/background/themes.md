# 主題風格候選（T01~T10）

- 只決定風格，尚未出圖；色碼是方向參考，不是最終配色
- 名稱顯示在首頁 D02 中間文字區（240px 寬），4 字以內放得下

## 整體節奏

- 前 3 個主題（第 1~60 關）明亮平和：草原、森林、沙漠，亮度高、色彩飽和，讓新手安心
- 中段（第 61~120 關）開始變危險：毒沼、火山、深海，色調變暗，對應第 60 關起解鎖的毒物、黑暗、混亂、燃燒、狂暴
- 後段（第 121~200 關）冷暗壓迫：冰原、雷雲、古堡、深淵，最後一個主題最暗、對比最強
- 對應關係只是呼應（毒沼配毒物、火山配燃燒），不改任何遊戲規則
