# Bricklite 品牌圖設計稿(圖示、Logo、載入畫面)

- 狀態:圖片全部完成,待使用者逐項確認(D07、D08 使用者決定不做)
- 基準:Godot 4、Android 直式、畫面 360×640(原點左上,單位 px)
- 遊戲名稱:Bricklite(只有英文)
- 代號固定不重編;確認後由 PM 通知再刪除該項

## 視覺方向

| 項目 | 內容 |
|---|---|
| 主題 | 像素風打磚塊手機遊戲,給休閒玩家;圖示要在商店小圖(約 48px)也認得出「球 + 磚」 |
| 色彩 | 深底藍 #192331(圖示與載入底);磚彩虹色(沿用 `art/bricks/normal/`);球亮白藍(沿用 `art/ball/ball_normal.png`);擋板鋼藍灰(沿用 `art/paddle/paddle_normal_*.png`);強調光點暖黃 #FFD84D;Logo 描邊近黑 #0B0F1A |
| 字型 | 無字型檔;Logo 是圖。載入畫面不放文字 |
| 版面 | 見 D09 |
| 原則 | 1. 只用遊戲裡本來就有的元素 2. 每張圖在目標尺寸原生繪製(Logo 在載入畫面由程式放大,見 D04) 3. 小尺寸優先:主體大、顏色少、輪廓清楚 |

- 畫風:左上光源、深色描邊、立體感;調色盤不限定。

## 項目

1. [D01] Google Play 圖示 512×512:**已定稿**
   - 用途:Play Console「應用程式圖示」;也可當 Godot 專案 icon 的來源
   - 檔名:`art/branding/icon_play_512.png`
   - 規格:512×512,PNG,不透明(整面有底色 #192331);圓角由商店套用,圖不畫圓角;不含文字
   - 內容:彩虹磚牆置中、中央被球撞出裂洞,球帶暖黃光暈飛向右上

2. [D02] 自適應圖示前景:**已定稿**
   - 用途:Android 自適應圖示前景層
   - 檔名:`art/branding/icon_adaptive_fg_432.png`
   - 規格:432×432,透明底;PM 由 256 原圖置中補邊並下移 22px(不縮放)
   - 內容:彩虹磚牆 + 裂洞 + 白藍大球(暖黃光暈、火焰拖尾);不含擋板、文字、底色
   - 安全區:中央直徑 264 的圓(x 84~348、y 84~348)

3. [D03] 自適應圖示背景:**已定稿(不出圖)**
   - 純色 #192331,不含圖案;Godot 專案設定填色碼即可
   - 與 D01 底色一致

4. [D04] Title Logo「Bricklite」:**已定稿**
   - 檔名:`art/branding/logo_bricklite.png`
   - 原圖:256×64,透明底
   - 內容:粗體立體像素字 Bricklite,暖黃到橘色,小寫 i 的點是球,字下方細鋼藍灰擋板線;描邊 #0B0F1A
   - 載入畫面用法:由程式**放大 1.25 倍顯示為 320×80**,位置 x 20、y 200(水平置中);**nearest 取樣,不平滑**
   - 標題畫面:本階段不做,只提供 Logo 圖

5. [D05] 載入進度條外框:**已定稿**
   - 檔名:`art/branding/loading_bar_frame.png`
   - 規格:256×32,透明底;**透明窗口 x 20–235、y 8–21(216×14)**;窗口內全透明,填充從下面露出
   - 內容:鋼藍灰金屬外框 + 深描邊,單一連續外框
   - 用法:最上層,1:1 顯示

6. [D06] 進度條填充切片:**已定稿**
   - 檔名:`art/branding/loading_bar_fill_tile.png`
   - 規格:16×16,不透明,不需無縫(分格金磚,一格一格分開)
   - 內容:暖黃金磚,有磚紋,深色描邊、四角深色圓角
   - 用法:水平鋪滿 0~216px 窗口(最後一塊裁切);墊在外框下面,上下各 1px 被外框蓋住

7. [D07] 進度條空槽切片:**不做(使用者決定)**

   - 曾出暗色磚槽(job f9b9dfb7-d454-4abb-85bd-4f3026ae543a),未採用

8. [D08] 載入循環動畫:**不做(使用者決定)**
   - 載入畫面沒有動畫
   - 曾出第一格(job 1ceee5fd-1485-4571-a1a8-b9201e1f0005),未採用

9. [D09] 載入畫面版面(360×640):**已定稿**
   - 圖層(下到上):底色 #192331 → Logo(放大) → 金磚填充 → 外框

   | 元素 | x | y | 寬 | 高 | 說明 |
   |---|---|---|---|---|---|
   | 底色 | 0 | 0 | 360 | 640 | 純色 #192331(D10) |
   | Logo(D04) | 20 | 200 | 320 | 80 | 256×64 原圖放大 1.25 倍,nearest 取樣 |
   | 金磚填充(D06) | 72 | 527 | 0~216 | 16 | 寬度 = 216 × 進度(0~100%),鋪 16×16;最後一塊可裁切 |
   | 進度條外框(D05) | 52 | 520 | 256 | 32 | 最上層,1:1 |

   - 金磚一格一格填入,未填處露出 #192331 底色,不是連續填色
   - 進度條只有 2 片:外框 + 填充;沒有空槽、沒有動畫
   - 狀態:

   | 狀態 | 樣子 |
   |---|---|
   | 開始 0% | 只有 Logo 與外框,窗口內是底色 |
   | 載入中 | 金磚填充從左往右增加 |
   | 完成 100% | 填充滿 216px;停留不超過 0.3 秒後切換畫面(可調) |
   | 載入失敗 | 本階段不設計,待 PM 決定 |
