### 4.2 畫新圖的流程與注意事項

> **2026-10-27 使用者決定改流程(本節以下為舊流程,僅供參考):** 現有圖不變;之後新圖由 designer 用 pixel-loom(MCP)製作 → 使用者在 pixel-loom 看過確認後才匯出 PNG → 檔名照舊規則(全小寫 `dNN_名稱`)。不再使用 md 網格。designer 定義檔已開放 pixel-loom 工具並寫入規則(2026-10-27,使用者同意;不開放 cleanup/storage/generation 等)。未定案:新圖存放資料夾(每次派工時指定)、需要變化圖(七色、閃白)時的做法。designer 實際用 pixel-loom 出圖尚未試過。試用紀錄見 `docs/handoff-pixel-loom.md`。

1. PM 擬指令 → 給使用者看 → 派 designer(文字網格,一字元一像素,`.` 透明)。
2. PM 記錄 preview SHA256 → 轉檔 → verify → 比對雜湊,只有預期的圖與 `overview.png` 可變動。
3. designer 用 Read 看 `_x8` 自檢 → PM 用 SendUserFile 給使用者確認。圖片免 QA。
4. 需要新的自動產生規則時,派 engineer 改工具 → QA → JEV。
